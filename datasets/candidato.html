candidato — candidacy panel

One row per candidate-election appearance across every TSE cycle 1998–2024 (all offices, both rounds). Carries the person key (politico_id), party/coalition, office, geography (municipio_id, estado, ibge7), electoral outcome (votes, elected, margin), and candidate attributes (education, occupation, marital_status). This is politica's single biggest external dependency — ficha's cand table and the whole electoral spine are built from it.
